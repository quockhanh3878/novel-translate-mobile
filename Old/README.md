# MarianMT Chinese → Vietnamese (50M)

A lightweight MarianMT model for offline Chinese → Vietnamese translation.

This model has been fine-tuned on approximately **10GB** of high-quality bilingual Chinese–Vietnamese data and is optimized for **ONNX Runtime** on Android devices.

## Features

- 🇨🇳 Chinese → 🇻🇳 Vietnamese
- ~50 million parameters
- Fine-tuned on ~10GB dataset
- Offline translation
- ONNX Runtime compatible
- Optimized for Android
- Fast inference
- Lightweight memory usage

## Model Information

| Item | Value |
|------|------|
| Architecture | MarianMT |
| Parameters | ~50M |
| Framework | Transformers |
| Runtime | ONNX Runtime |
| Platform | Android / Windows / Linux |
| Language | Chinese → Vietnamese |

## Performance

- Fast inference on Android
- Low memory usage
- Suitable for novel translation
- Optimized for offline applications
