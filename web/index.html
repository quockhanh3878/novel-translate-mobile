01 Chọn nguồn truyện

Hỗ trợ link mục lục hoặc chương 1: uukanshu.cc, 69shuba.com, bgq99.cc, shubaow.net, biquge.tw, tianyabooks.com, wa01.com (hoặc file .txt/.html/.mhtml đã lưu).

Nhập file đã có để tiếp tục, không cần cào lại.

Tên và tác giả được ghi vào bìa, metadata EPUB/PDF. Sửa tên không làm mất tiến độ dịch; ngày xuất bản gốc chỉ ghi khi nguồn cung cấp.

Bản dịch, hồ sơ sách, EPUB và PDF được lưu tại đây. Nếu nhập URL, file thô cũng lưu cùng thư mục.

03 Phạm vi dịch

Mặc định dịch dữ liệu đã cào, chuẩn bị tên riêng và thành ngữ trước khi dịch. Các chương đã hoàn thành được bỏ qua khi chạy tiếp.

Dịch ngay từng chương, bỏ qua bước chuẩn bị từ điển toàn truyện. Tên và thành ngữ được bổ sung dần.

0 = đến hết dữ liệu

Để trống: tự cào tiếp sau chương cuối đã có. Chỉ nhập khi cào tiếp bị kẹt hoặc sai chỗ, ví dụ 850 = bắt đầu từ chương 850 của trang. Chương mới được nối vào cuối file thô, bản dịch cũ giữ nguyên. Chỉ áp dụng cho lần chạy này.

    Nếu cào hoặc dịch bị dừng giữa chừng (mất mạng, tắt app...), chỉ cần nhập lại thông tin cũ và bấm chạy lại. Các chương đã xong được giữ nguyên, hệ thống tiếp tục từ chương dang dở và tự động bỏ qua bước đóng gói lại nếu file EPUB/PDF đã khớp bản dịch mới nhất.

    Sửa chương bằng file có sẵn

    Nếu có chương bị cào sai hoặc cần thay bằng bản đúng (file TXT theo định dạng file thô, hoặc trang HTML/MHTML đã lưu), bấm "Nạp file chương sửa". Chương có cùng số trong tiêu đề sẽ được thay; chương chưa có sẽ được thêm vào cuối rồi sắp lại. Chương đã thay được dịch lại, các chương khác giữ nguyên bản dịch. Bản cũ được lưu thành *.truoc-nap.bak.

    Chạy và kiểm tra tiến trình trên Termux

    Khởi chạy giao diện web hoặc cập nhật trên Termux:

    bash ~/novel/update_termux.sh

    Xem nhật ký máy chủ web hoặc kiểm tra tiến trình Python:

    tail -n 30 ~/novel/web_gui.log && ps -ef | grep python

    Với trang chặn Cloudflare Turnstile (như biquge.tw), có thể lưu trang chương từ trình duyệt thành file HTML/MHTML rồi chọn ở nút tải file phía trên, hoặc cài Chromium headless trên Termux (pkg install tur-repo && pkg install chromium).

    Lấy file EPUB/PDF ra điện thoại (Termux)

    Khi dịch xong, ứng dụng tự động chép EPUB/PDF ra thư mục Documents hoặc Download của điện thoại (nếu đã chạy termux-setup-storage). Bạn cũng có thể bấm "Tải EPUB" hoặc "Tải PDF" ở cuối trang, hoặc chép thủ công:

    cp ~/novel/*.{epub,pdf} ~/storage/shared/Download/
    Vị trí lưu file (máy tính)

    Truyện thô, bản dịch, EPUB và PDF nằm trong thư mục:

    Bấm "Mở thư mục dữ liệu" ở cuối trang để mở nhanh. EPUB và PDF được tạo khi bạn bấm "Tải EPUB" hoặc "Tải PDF" ở cuối trang.
