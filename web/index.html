    Nếu cào hoặc dịch bị dừng giữa chừng (mất mạng, tắt app...), chỉ cần nhập lại thông tin cũ và bấm chạy lại. Các chương đã xong được giữ nguyên, hệ thống tiếp tục từ chương dang dở. Thông tin lần chạy trước được nhớ sẵn trong ô nhập.

    Kiểm tra tiến trình chạy ẩn (Termux)

    Mở cửa sổ Termux mới và nhập lệnh để kiểm tra Python có đang chạy không:

    ps -ef | grep python

    Xem nhật ký mới nhất:

    tail -n 20 ~/novel/pipeline_*.log

    Tắt cưỡng bức:

    pkill -f python
    Lấy file EPUB/PDF ra điện thoại (Termux)

    Mọi file nằm trong thư mục ~/novel. Đưa EPUB/PDF ra thư mục Download:

    cp ~/novel/*.{epub,pdf} /sdcard/Download/
    Vị trí lưu file (máy tính)
