TRÌNH DỊCH TRUYỆN DEEPSEEK {{VERSION}} (Windows)

CÁCH DÙNG
1. Giải nén cả thư mục NovelTranslator ra nơi ghi được (Desktop, ổ D...). Không chạy thẳng trong file zip.
2. Bấm đúp NovelTranslator.exe. Cửa sổ đen hiện ra và trình duyệt tự mở trang dịch truyện.
3. Lần đầu: dán DeepSeek API Key (sk-...) vào ô API Key, bấm "Lưu Key".
4. Nhập URL chương 1 hoặc chọn file truyện thô .txt, bấm "Bắt đầu dịch".
5. Truyện đã dịch nằm ở mục "Truyện đã dịch" trên trang, bấm "Tải EPUB". Hoặc mở thư mục DuLieu cạnh file .exe
   (nút "Mở thư mục dữ liệu" ở cuối trang).

TẮT ỨNG DỤNG
Bấm "Thoát ứng dụng" ở cuối trang, hoặc đóng cửa sổ đen. Việc dịch đang chạy sẽ dừng, lần sau chạy lại đúng truyện
sẽ tự tiếp tục từ chương dang dở.

CẬP NHẬT
Giải nén bản mới ra thư mục mới, sau đó chép thư mục DuLieu cũ vào cạnh file .exe mới.

LƯU Ý
- Windows có thể hiện cảnh báo SmartScreen ở lần chạy đầu vì ứng dụng chưa ký số: bấm "Thông tin thêm" rồi "Vẫn chạy".
- Mọi dữ liệu (API Key, truyện, EPUB) chỉ nằm trong thư mục DuLieu trên máy này. Ứng dụng chỉ mở trên máy này
  (127.0.0.1), máy khác trong mạng không truy cập được.
- Cổng 8000 bị chiếm thì ứng dụng tự chọn cổng khác, địa chỉ hiện trong cửa sổ đen.
- Kiểm tra gói cài: mở cmd trong thư mục này và chạy NovelTranslator.exe --selftest
